# SAMPLE-DATA-ANALYTICS-PROJECT
This repository contains a complete data analysis project where raw data was cleaned and transformed using Python, and meaningful insights were visualized using Power BI.

📊 Sales & Profit Analysis Project (Python + Power BI)

🔍 Project Overview

This project focuses on analyzing sales and profit data to identify business insights such as monthly sales trends, profit by product, country-wise performance, and loss analysis.
The analysis is performed using Python (Jupyter Notebook) for data cleaning and exploration, and Power BI for interactive dashboard visualization.

🛠 Tools & Technologies Used

Python

Pandas

NumPy

Matplotlib / Seaborn

Jupyter Notebook


Power BI

GitHub (for version control and project sharing)


🧹 Data Cleaning & Preparation (Python)

The dataset was first cleaned and prepared using Python.

Key steps include:

Handling null/missing values

Removing inconsistencies

Converting data types (dates, numbers)

Creating derived columns for analysis

📈 Exploratory Data Analysis (EDA)

The following analyses were performed in Python:


1️⃣ Sales by Month

Identified monthly sales trends

Helped understand seasonal patterns

Useful for demand forecasting


2️⃣ Profit by Product

Compared profit across different products

Identified high-performing and low-performing products


3️⃣ Sales & Profit by Country

Analyzed geographical performance

Highlighted countries contributing most to revenue and profit


4️⃣ Profit Analysis

Studied overall profit distribution

Identified profit-driving segments


5️⃣ Loss Analysis

Detected loss-making products and regions

Provided insights for cost control and pricing strategy


📊 Power BI Dashboard

An interactive dashboard was created in Power BI using the cleaned dataset.


Dashboard Features:

📅 Monthly Sales Trends

📦 Product-wise Profit Analysis

🌍 Country-wise Sales & Profit

📉 Loss-Making Products & Regions

🎯 KPI Cards (Sales, Profit, Loss)
